# Jira Stories

## Epic

Mobile Automation - AMP Appium Framework

## Story 1

As a QA engineer, I want to create an Appium mobile automation framework so that AMP mobile flows can be tested on Android emulator.

### Acceptance Criteria

- Maven Appium project exists inside `appium-tests`.
- Android driver setup is reusable.
- Config values are externalized.
- Base test setup starts and quits driver.
- Page Object structure exists.
- README explains install and run steps.

## Story 2

As a customer, I want to log into the AMP mobile app so that I can access my account dashboard.

### Acceptance Criteria

- Valid user can enter username and password.
- Login button submits credentials.
- Successful login shows dashboard screen.
- Invalid login shows error message.
- Empty credentials show validation error.
